# Koivest Production Prototype V6

This is a static production prototype designed for direct deployment to GitHub Pages.

## Core interaction
- Screen 1: KOIVEST hero only — no numbered UI.
- Screen 2: pinned scroll sequence:
  1. We build. — particles gather into an orbital form.
  2. We operate. — particles become a directional wave.
  3. We allocate. — particles expand into a capital/network sphere.
  4. Transition to: “An investment & operating company built for the long term.”
- No 01 / 02 / 03 numbering in the Hero or storytelling screen.
- Portfolio includes KOICOIN and KOINEX only.

## Deploy on GitHub Pages
1. Create a GitHub repository.
2. Upload all files from this folder to the repository root.
3. In GitHub: Settings → Pages.
4. Under Build and deployment, choose “Deploy from a branch”.
5. Select `main` and `/ (root)`.
6. Save. GitHub will provide your live Pages URL.

## Visual direction
Black / charcoal base, warm ivory typography, restrained champagne-gold particles. Gold is intentionally used as an atmospheric accent rather than a dominant “black + gold luxury” treatment.
